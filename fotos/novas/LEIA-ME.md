# Suba aqui suas fotos reais

Arraste as fotos para esta pasta (no GitHub: **Add file > Upload files**). O squad cataloga cada uma sozinho no próximo post e move para `fotos/`.

Dicas para virarem boas artes:
- **Variedade:** palco, estúdio, trabalhando no computador, com o sax, gravando, dando aula, bastidor.
- **Vertical** de preferência, com algum espaço livre acima ou abaixo de você.
- Boa resolução (a foto original do celular serve; evite print de WhatsApp).
- Se quiser que o squad saiba o contexto, coloque no nome do arquivo. Ex.: `palestra-acil-lajeado-2026.jpg`.

Fotos com sua família só entram se você pedir em `pautas/ideias.md`.
